# Smokes and Alcohol Psy Relief

A mod for **S.T.A.L.K.E.R. Anomaly G.A.M.M.A.** by Expand.

**[Download (Releases)](https://github.com/expand0501/smokes-alcohol-psy-relief/releases)** · [Русский](#русский)

A smoke break or a drink calms the nerves; it doesn't flush radiation. Smokes restore psy health instead of
radiation. Alcohol keeps its radiation restore and also restores psy health.

## Features

- Smokes (all cigarettes, the Cuban cigar, tobacco) no longer restore radiation; their other stats stay as they are.
- Smokes and alcohol restore psy health gradually while the item's effect lasts; several items stack.
- Smokes and alcohol added by other mods are detected automatically.
- Being drunk boosts psy restore and gives psy protection.
- Separate strength presets for smokes and alcohol in MCM (Light / Mild / Medium / Potent / Strong).
- Tooltip row in the item's stats block: how much psy health one use restores.
- No game file replaced (DLTX), no per-frame work while nothing is being restored and you are sober.

## Installation (Mod Organizer 2)

1. Install the zip from [Releases](https://github.com/expand0501/smokes-alcohol-psy-relief/releases) as a new mod.
2. Any position in the load order.
3. In game: MCM > Smokes and Alcohol Psy Relief. Safe to add to an existing save.

The full manual is in [`src/readme.md`](src/readme.md) (also inside the zip).
Changes per version: [`CHANGELOG.md`](CHANGELOG.md).

## Русский

Мод для **S.T.A.L.K.E.R. Anomaly G.A.M.M.A.**, автор Expand.

**[Скачать (Releases)](https://github.com/expand0501/smokes-alcohol-psy-relief/releases)**

Перекур или глоток спиртного успокаивают нервы, но радиацию не выводят. Курево восстанавливает пси-здоровье вместо
выведения радиации. Алкоголь по-прежнему выводит радиацию и вдобавок восстанавливает пси-здоровье.

### Возможности

- Курево (все сигареты, кубинская сигара, табак) больше не выводит радиацию; остальные его свойства не изменены.
- Курево и алкоголь постепенно восстанавливают пси-здоровье, пока действует предмет; эффекты складываются.
- Курево и алкоголь из других модов определяются автоматически.
- Опьянение усиливает восстановление пси и даёт пси-защиту.
- Отдельные пресеты силы для курева и алкоголя в MCM (Слабо / Умеренно / Средне / Крепко / Сильно).
- Строка в характеристиках предмета: сколько пси-здоровья даёт одно использование.
- Игровые файлы не заменяются (DLTX), без нагрузки каждый кадр, пока ничего не восстанавливается и вы трезвы.

### Установка (Mod Organizer 2)

1. Установите zip из [Releases](https://github.com/expand0501/smokes-alcohol-psy-relief/releases) как новый мод.
2. Любое место в порядке загрузки.
3. В игре: MCM > Курево и выпивка помогают психике. Можно ставить на текущее сохранение.

Полное описание (на английском) — в [`src/readme.md`](src/readme.md), он же лежит в архиве.
